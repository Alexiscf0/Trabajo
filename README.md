# 📍 Local-izados

**Local-izados** es una aplicación interactiva desarrollada en **Java** con el entorno de desarrollo **Eclipse**. Esta app tiene como objetivo facilitar el descubrimiento, consulta y valoración de locales de ocio, como discotecas, bares, cafeterías y muchos otros tipos de negocios. 🕺🍻☕🍴

A través de una interfaz intuitiva, el usuario puede navegar entre distintas páginas dentro de la app, consultar información detallada de cada local, dejar reseñas y guardar valoraciones, haciendo uso de un sistema de autenticación con registro e inicio de sesión.

---

## 🧭 Navegación de la App

La aplicación está compuesta por varias ventanas conectadas entre sí de forma interactiva. Cada ventana tiene una función específica, que guía al usuario en su experiencia de exploración de locales:

- 🏠 **Pantalla principal:** Muestra un menú donde puedes elegir el tipo de local que deseas consultar.
- 🗂️ **Catálogo de locales:** Según el tipo seleccionado, se muestran modelos de locales relacionados.
- 🔍 **Vista del local:** Al seleccionar uno, se despliega una vista con todos los detalles importantes.
- 📝 **Reseñas:** Sección para escribir y ver valoraciones de otros usuarios.
- 🔐 **Autenticación:** Sistema de registro e inicio de sesión para poder enviar reseñas.

---

## 📌 ¿Qué puedes hacer con Local-izados?

### 🏙️ Explorar locales
El usuario puede elegir entre diferentes tipos de negocios:
- 🕺 Discotecas
- 🍻 Bares
- ☕ Cafeterías
- 🍽️ Restaurantes
- 🎮 Salones recreativos
- 🎤 Karaokes
- ¡Y más!

### ℹ️ Consultar información
Cada local muestra:
- 📛 Nombre del establecimiento
- 📍 Ubicación o dirección
- ⭐ Valoración general (según opiniones de usuarios)
- 🏷️ Tipo de negocio al que pertenece

### ✍️ Escribir reseñas
- Puedes escribir tu propia opinión sobre un local.
- Para ello, deberás:
  1. Buscar el negocio deseado.
  2. Redactar tu reseña.
  3. Registrarte o iniciar sesión.
  4. La reseña se guardará automáticamente en la base de datos.

## 🛠️ Tecnologías utilizadas

| Tecnología      | Descripción                                         |
|----------------|-----------------------------------------------------|
| ☕ Java         | Lenguaje principal utilizado para la lógica de la app |
| 🧩 Eclipse IDE | Entorno de desarrollo donde se ha creado el proyecto |
| 🗃️ MySQL / JDBC (opcional) | Posible conexión a base de datos para guardar usuarios y reseñas |
| 🖼️ Swing / AWT | Bibliotecas utilizadas para la interfaz gráfica de usuario |

> 🔒 Todas las reseñas están asociadas a usuarios autenticados, lo que garantiza fiabilidad en las valoraciones.
